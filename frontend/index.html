    Como llevar la imagen a esta PC

    Si la imagen redroid se armo en otra maquina:

    docker save <imagen> | gzip > imagen.tar.gz
# copiar el archivo a esta PC, despues:
gunzip -c imagen.tar.gz | docker load

    Si esta pusheada a un registry propio: docker pull <tu-registry>/<imagen>

    Requisitos de host

    • Docker instalado y corriendo.
    • binderfs montado en /dev/binderfs (ver tab Doctor para el comando exacto).
    • mac80211_hwsim disponible si vas a usar imagenes con WiFi falso.
    • GPU + drivers si queres aceleracion (gpuMode=host).

    Levantar este manager

    docker compose up -d --build

    La tab Doctor va a decirte exactamente que falta configurar en este host, con el comando para arreglarlo.
